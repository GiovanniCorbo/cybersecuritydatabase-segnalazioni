# Cybersecurity Database – Segnalazioni

Segnalazioni pubbliche per [www.cybersecuritydatabase.org](https://www.cybersecuritydatabase.org): documenti mancanti, errori nelle schede, link non funzionanti, richieste di rimozione.

👉 [Apri una segnalazione](../../issues/new?template=segnalazione.yml)

Le segnalazioni vengono verificate dalla redazione prima di qualunque modifica al sito. Questo repository contiene solo le segnalazioni: il codice del sito non è pubblico. I dati (metadati e riassunti, licenza CC BY 4.0) si scaricano dalla pagina [Open data](https://www.cybersecuritydatabase.org/it/open-data/).

**Vulnerabilità di sicurezza**: non aprire una issue pubblica, scrivi a support@cybersecuritydatabase.org.

---

Public reports for [www.cybersecuritydatabase.org](https://www.cybersecuritydatabase.org): missing documents, errors, broken links, takedown requests. [Open a report](../../issues/new?template=segnalazione.yml). Security vulnerabilities: please email support@cybersecuritydatabase.org instead of opening a public issue.
